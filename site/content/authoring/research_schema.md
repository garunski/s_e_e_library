The S.E.E. Research wire contract exposes 28 scoped HTTP and MCP operations for research, report, analysis and guide. Runtime profile descriptors are version 1; knowledge_research_profile_get defines their required roles and rules.

## Availability and discovery

Enable knowledge_research in Project settings > Experimental for the explicit target project. It defaults to false. Disabling preserves documents, pages and immutable editions while omitting Research views, shared search hits, exact-project resources and qualified prompts. Calls return EXPERIMENTAL_FEATURE_DISABLED. Ordinary knowledge docs and decisions remain available. Mixed-project discovery can advertise tools enabled elsewhere; invocation still checks the explicit target project. Start with knowledge_research_profile_get and knowledge_research_list.

## Payload boundaries and selectors

Document and page get return metadata, counts and document_token or page_token only. Section get and source get return one complete record and section_token or source_token. Document/page metadata reject nested child bodies. Creation allocates research_id; stable child keys are create-if-absent. Mutation responses contain affected records and tokens, with bounded diagnostics; membership changes also return the changed parent token. All request and response schemas are defined in the machine schema, including the structured error envelope.

Document and page manifests, independent section/source files and immutable edition directories are the storage boundaries. Ordinary reads and writes never reconstruct a full ResearchDocument or ResearchWorkingCopy. Use section_put with section_token, source_put with source_token, document put with document_token and page put with page_token. Page create/pages_reorder require document_token; section create/sections_reorder require page_token. Page delete requires page_token and document_token; section delete requires section_token and page_token. Deletions require confirm=true. Publish and whole-document delete use tree_token from current validation. Source create needs no parent token. A stale token requires rereading and reconciling only the affected record.

Lists default to 25, accept 1..100 and return items, next_cursor and limit. The document catalogue retains the shared typed metadata filters envelope, discovered using list_filter_get for knowledge_research: filters compose with kind, tag, query and state using AND before pagination. MCP sends a predicate array; HTTP/resource queries encode the JSON array once as filters. See collection-filter.schema.json. Catalogue state=all|draft|published is distinct from content view=default|draft|edition. Default reads resolve the latest edition or unpublished draft; view=edition requires edition_id, rejected for other views. Pin the resolved view/edition and normalized filter selection while following opaque continuations; restart invalid/stale cursors. Protocol tools/list cursors are independent.

Search uses knowledge_research_search and GET /api/projects/{project}/knowledge/research/search. Query is required, 1..256 Unicode characters, with AND terms and no regex. Filters include research_id, page_key, kind, role, tag, view and edition_id; edition_id requires research_id. Hits carry section identities and snippets at most 240 characters, never full bodies. Edition metadata uses edition_list/edition_get; exact-edition page/section/source reads use view=edition and edition_id. Resource reads never mutate or fetch external sources.

## Errors and publication

The scoped error envelope has code, affected_ids, field_path, remedy and optional current_token. HTTP 400: invalid_key, invalid_order, invalid_filter, invalid_cursor, stale_cursor, unknown_fields, missing_token. HTTP 404: not_found, view_not_found. HTTP 409: stale_token, already_exists, referenced_source, nonempty_page, tree_changed. HTTP 422: invalid_content, invalid_publication. Project/auth admission errors retain existing semantics without foreign identity disclosure, including MISSING_PROJECT, PROJECT_NOT_GRANTED and EXPERIMENTAL_FEATURE_DISABLED. Applicable operation errors are listed on the authoring page and in x-operations.

Follow every validate diagnostics page, repair affected records and revalidate. Publication recomputes and validates the exact tree before creating an immutable separate-files edition. Publish only when requested. Small-page guidance (3-8 sections and about 1500 words) is advisory; preserve supplied long content without truncation, summarization or automatic splitting.
