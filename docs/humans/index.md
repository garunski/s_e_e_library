# Human docs

Authoring guides for each library piece type. Start with the piece you are
creating, then follow [Publish to the catalog](./publish.md) to add it to the
manifest.

## Piece types

- [Commands](./commands.md): agent runner definitions (`command.json`)
- [Prompts](./prompts.md): reusable system prompts (`prompt.json`)
- [Skills](./skills.md): agent SKILL.md guides
- [Workflows](./workflows.md): multi-step engine definitions (`definition.json`)
- [Bundles](./bundles.md): install several packages together

## Publishing

- [Publish to the catalog](./publish.md): payload layout, `catalog.json`, and validation
